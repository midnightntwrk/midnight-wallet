Add the reference DApp Connector implementation and its pluggable conformance suite. The package provides a complete
ConnectedAPI over the Wallet Facade (connection lifecycle, addresses, balances, transaction history, transfers, swap
intents, balancing, submission, data signing, and proving delegation), plus a spec-derived conformance suite that
external DApp Connector implementations can run unchanged against their own backend.
